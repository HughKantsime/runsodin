Corresponding source
--------------------
The matching sources are in the obico-server project at commit
1e7abb0bdf1c185b38a913d8bdbdbc3daa3df634 (2023-05-14), the commit that
published this ONNX file next to the Darknet weights it was made from:
https://github.com/TheSpaghettiDetective/obico-server/tree/1e7abb0bdf1c185b38a913d8bdbdbc3daa3df634/ml_api/model

  Darknet weights  https://tsd-pub-static.s3.amazonaws.com/ml-models/model-weights-8be06cde4e.darknet

  model.cfg        network definition at that commit (copy: obico-model.cfg)
  names            class names (copy: obico-model.names)

Later obico-server commits replaced the Darknet weights (2025-12-18) without
regenerating this ONNX file, so use the files at the commit above, not the
newest ones. Obico produced the ONNX file from those Darknet weights; O.D.I.N.
did not convert, retrain or otherwise modify it. Obico's model and training
notes for that version are in docs/model_development.md at the same commit:
https://github.com/TheSpaghettiDetective/obico-server/blob/1e7abb0bdf1c185b38a913d8bdbdbc3daa3df634/docs/model_development.md
