Design and scope

  • New anycubic_lan adapter implements the Phase A signed HTTP/AES-CBC handshake, self-signed MQTT TLS with client certificate and password-only fallback. Network connections use ODIN's validated, pinned configured destination. Firmware-supplied control/broker hosts cannot redirect the connection elsewhere.
  • Only query/getInfo can enter the publish path, additionally restricted to approved report-type/action pairs. The generic command router explicitly rejects Anycubic before the Bambu fallback; the existing dispatch allowlist remains unchanged.
  • Credentials exist only in memory. Each adapter connection handshakes afresh; cert/key files use mode 0600 in a private temporary directory and are removed immediately after loading the TLS context. API creation/update/setup reject user-supplied credentials. Log redaction covers device credentials, PEM blocks and upload s= tokens.
  • Poll info, multiColorBox getInfo, tempature and fan every 30 seconds. Consume pushed temperature, fan and print progress. Handshake, MQTT/publish failure, and lifecycle info staleness over 90 seconds mark the printer offline. Reconcile active printers and changed connection configurations periodically.
  • Parser uses the report topic type, wire spellings tempature/stoped, authoritative pause flags, and preserves the last understood state for unknown wire values. ACE fields merge by box id and zero-based slot index, preserving known values on null updates. Empty material denotes an empty slot. Zero consumables_percent with empty sku is unknown remaining.
  • ACE Pro 40001 and ACE 2 40002 retain separate identities. ODIN slot number = box id × 4 + wire index + 1. Updates preserve existing row IDs, spool IDs and confirmations; the API assignment/restart replay test proves this on the real bootstrapped schema. Environment readings enter ams_telemetry; existing inventory supplies remaining grams/percentage from an assigned spool.
  • The monitor reuses Elegoo's common lifecycle/telemetry sink. Elegoo behavior is byte-identical to origin/main; Anycubic normalizes lifecycle values before entering the inherited sink and withholds callbacks that have no live lifecycle yet.
  • Model names derive from /info modelId: known IDs 20024, 20025, 20026, 20027, 20029; unknown IDs pass through, including undocumented 20028. FLV URL http://configured-host:18088/flv is registered with existing camera discovery/go2rtc handling.
  • Registered in both supervisord configurations, daemon manifest, database application names, log viewer, troubleshooting, release log collection and service health checks. PrinterModal accepts IP-only setup; printer cards group ACE boxes and use existing slot editing/spool assignment.
  • No DB migration: api_type is already a String column. No production printer record was migrated, and no Education protocol allowlist or policy inventory was extended. Controls, upload and dispatch remain outside Phase C.
