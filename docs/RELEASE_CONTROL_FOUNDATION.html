ODIN Release-Control Foundation

Implemented locally: controlled validation and fail-closed local release entry points.

What this establishes

  • One manually dispatched, owner-bound validation workflow for an exact candidate ref and SHA.
  • Ten ordered validation areas with structured JSON, JUnit, and HTML evidence.
  • Isolated installer/update smoke resources with collision refusal and identity-bound cleanup.
  • make release disabled; version bumping creates a local commit only.

Claim boundary

This foundation is not yet installed on GitHub, does not publish an image, and does not deploy staging or production. Those actions belong to the successor authorization and promotion specs.
