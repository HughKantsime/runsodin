ODIN Practical Release Evidence

Purpose: turn one complete trusted-validation run into a small, deterministic, tamper-evident artifact that can be checked before promotion.

What the bundle proves

  • The aggregate and all ten CV01–CV10 component results passed without failures, skips, xfails, timeouts, or findings.
  • Candidate, database-parity, EDU-sandbox, and hardware evidence resolve to the expected source commit and a clean source tree.
  • Every raw validation file was hashed on the trusted runner. Raw logs are not included in the promotion artifact.
  • The canonical manifest's exact bytes are bound to manifest.sha256.

What it does not prove

A passing validation run does not authorize stage, demo, or production changes. Each action requires a separate owner-dispatched promotion run. Production also requires the protected GitHub environment review.

Files

  • manifest.json — authoritative canonical evidence
  • manifest.sha256 — digest of those exact bytes
  • index.html — readable mirror for operators

Local verification

make verify-practical-evidence EVIDENCE_DIR=<run>/evidence PYTHON=python3.11
