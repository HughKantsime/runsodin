# Historical Release Instructions

This directory contains dated implementation plans. Any commands in those
plans that push a branch or tag, publish a mutable image, dispatch another
repository, or deploy production are historical records only and are not
operative instructions.

Current release behavior is defined by `ops/README.md`, `ops/RUNBOOK.md`, and
the reviewed release-control specs. The local foundation performs validation
only; publishing and production promotion remain unavailable until their
successor workflows are implemented and authorized.
