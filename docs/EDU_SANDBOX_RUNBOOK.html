ODIN Education Sandbox

An isolated, fictional proof-of-concept lifecycle. It does not deploy, contact the license service, mint licenses, or connect to real printers.

Safety model

  • Unique validated IDs and label-owned Docker resources.
  • ODIN, the broker, and simulator have only an internal network; a read-only, capability-dropped proxy with no secret/data mounts is the sole edge member and binds dynamic loopback-only HTTP. MQTT is never published.
  • One exact candidate image for the app, proxy, and replay publisher.
  • Random 0600 file secrets; no credential values in argv, Compose metadata, state, logs, JSON, or HTML.
  • ACTIVE requires a normally signed, installation-bound Education license.

1. Prepare

make edu-sandbox-prepare EDU_SANDBOX_ID=ctec-poc
make edu-sandbox-status EDU_SANDBOX_ID=ctec-poc

The application is verified and stopped. No Education capability is claimed. After an interrupted preparation, use the bounded python3.11 -m ops.edu_sandbox prepare ctec-poc --recover path; it verifies ownership before removing partial resources.

2. Proof-of-possession request

Use hidden terminal prompts so the key and nonce never enter shell arguments, history, or environment variables. This helper writes the bounded JSON request only to the lifecycle command's non-TTY stdin.

python3.11 - <<'PY'
import getpass, json, subprocess
request = {
    "key": getpass.getpass("ODIN license key: "),
    "nonce": getpass.getpass("Single-use issuer nonce: "),
}
subprocess.run(
    ["make", "edu-sandbox-request-license", "EDU_SANDBOX_ID=ctec-poc"],
    input=json.dumps(request).encode(),
    check=True,
)
PY

Deliver the 0600 activation request to the existing issuer through the approved secure channel. Public evidence contains only its digest.

3. Activate

make edu-sandbox-activate EDU_SANDBOX_ID=ctec-poc \
  EDU_EXPIRES_AT=2026-10-15T23:59:59Z < signed-odin-license.txt

ODIN verifies signature, tier, binding, installation, expiry, digest, internal-only app networking, loopback proxy isolation, personas, roles, tenant graph, report access, exact images, and synthetic replay.

4. Status and reset

make edu-sandbox-status EDU_SANDBOX_ID=ctec-poc
make edu-sandbox-reset EDU_SANDBOX_ID=ctec-poc

Reset preserves installation/device/license identity while replacing mutable data. A failed reset becomes DEGRADED.

5. Expire and reconcile

make edu-sandbox-expire EDU_SANDBOX_ID=ctec-poc
make edu-sandbox-reconcile EDU_SANDBOX_ID=ctec-poc

Reconciliation stops the application and publisher. The repository includes a one-shot scheduler example but installs nothing.

6. Certify or purge

make edu-sandbox-certify EDU_SANDBOX_ID=ctec-poc
make edu-sandbox-purge EDU_SANDBOX_ID=ctec-poc

Full certification resets, expires, and purges. Without the external signed license it reports BLOCKED_EXTERNAL, never PASS.

Purge verifies labelled containers, volumes, both networks, the candidate tag, license mount, heartbeat volume, controller directory, and prior loopback port are absent. JSON and clickable HTML tombstones remain; the sandbox ID is then terminal.

Evidence and failure rules

HTML/JSON/JUnit evidence is written under artifacts/edu-sandbox/. Foreign labels, symlinks, state drift, stale replay, wrong images, wrong roles, or residue fail closed. A failed renewal restores the prior expired bound license or becomes DEGRADED. Send school IT only sanitized evidence and transfer credentials through an approved password manager or encrypted channel.
